# المراسلات الرسمية — تطبيق Android

تطبيق Android لتوليد الرسائل الرسمية العربية المطبوعة (على الورق المروّس)
بالذكاء الاصطناعي، وتصديرها **PDF** ومشاركتها مباشرة، مع أرشيف كامل وترقيم
مرجعي تلقائي — **كل البيانات محلية على الجهاز بلا أي خادم بعيد**.

هذا هو الإصدار المحمول من نظام
[المراسلات الرسمية](https://github.com/wosoolsoft/correspondence) لسطح المكتب،
بنفس مخطط قاعدة البيانات ونفس منطق الصياغة والترقيم.

## المزايا

- **توليد بالذكاء الاصطناعي**: اختر المنشأة والجهة ونوع الرسالة و**حدّة الرسالة**
  (ودّية / رسمية محايدة / حازمة / شديدة اللهجة)، واكتب المضمون بلغتك العادية.
- **تحرير كامل**: كل الحقول والفقرات والنقاط والجداول قابلة للتحرير، مع
  **التنقيح بالذكاء** («اجعل النبرة أشد حزمًا» فيعيد الصياغة).
- **تصدير PDF وWord (DOCX)**: بنفس مواصفات نسخة سطح المكتب — صفحة Letter،
  الترويسة صورة خلف النص، إطار موحّد للتاريخ (الهجري اختياري) والمرجع،
  كتلة توقيع، وترقيم «صفحة X من Y» — ومشاركة مباشرة عبر واتساب والبريد.
  ملف Word يُبنى بكتابة OOXML مباشرة بنفس بنية محرك سطح المكتب (بما فيها
  خطا DIN Next LT Arabic وDecoType Thuluth)، فيفتح في Microsoft Word
  قابلًا للتحرير كأنه صادر من نسخة Windows.
- **الترقيم التسلسلي المزدوج**: مرجع عام `السنة-التسلسل` لكل منشأة وسنة،
  وتسلسل خاص برسائل كل منشأة إلى كل جهة.
- **أرشيف** بتبويبي **الصادر** و**الوارد** مع البحث والتصفية، و**جهات مستلمة**
  تُحفظ تلقائيًا مع لقب المخاطبة، و**منشآت** متعددة بترويساتها.
- **الإشارة إلى مراسلات سابقة**: اختر رسائل صادرة من الأرشيف أو كتبًا واردة
  مسجّلة، فيفتتح الذكاء الاصطناعي الرسالة بصيغة الإشارة الرسمية الصحيحة
  («بالإشارة إلى كتابنا/كتابكم رقم (…) وتاريخ …») ملتزمًا بوقائعها حرفيًا.
- **سلسلة المراسلات**: خيط زمني في المحرر يجمع كل الصادر والوارد المرتبط
  بالقضية نفسها — حتى عبر أكثر من درجة.
- **القوالب الشخصية**: «حفظ كقالب» من المحرر، ثم إنشاء فوري من القالب
  بمرجع وتاريخ جديدين دون استهلاك ذكاء اصطناعي.
- **نسخ احتياطي واستيراد**: تصدير قاعدة البيانات كاملة ومشاركتها، واستيراد
  نسخة سابقة — بما فيها **قاعدة نسخة Windows** (تُطبَّق ترحيلات المخطط
  تلقائيًا وتُحفظ نسخة أمان قبل الاستبدال).
- **🎨 مصمّم الترويسة**: لا تملك ورقًا مروّسًا؟ ولّد ترويسة احترافية من
  بيانات المنشأة بثلاثة قوالب (كلاسيكي / شريط ملوّن / بسيط أنيق) مع اختيار
  اللون وشعار اختياري ومعاينة حية — تُولَّد بدقة الطباعة الكاملة
  (2550×3300 ≈ 300DPI) وتُعتمد ترويسةً للمنشأة فورًا. القوالب والإحداثيات
  نفسها في نسخة سطح المكتب، فالترويسات متطابقة بين المنصتين.

## مزودات الذكاء الاصطناعي

نفس مزودات نسخة سطح المكتب: OpenAI وAnthropic (Claude) وOpenRouter وGroq
وDeepSeek وTogether AI وOllama (على حاسوبك في الشبكة المحلية) وأي مزود متوافق
مع OpenAI API. المفتاح يُدخل من صفحة «الإعدادات» ويُحفظ **مشفّرًا في
Android Keystore**، مع رابط مباشر لإنشاء المفتاح لدى كل مزود وزر اختبار
للاتصال. بدون مفتاح: زر «توليد تجريبي».

## البنية التقنية

| المكوّن | التقنية |
| --- | --- |
| الإطار | Flutter (Dart)، واجهة عربية RTL بالكامل |
| قاعدة البيانات | SQLite عبر sqflite — نفس مخطط نسخة سطح المكتب |
| المفاتيح | flutter_secure_storage (Android Keystore) |
| توليد PDF | حزمة pdf + printing (معاينة ومشاركة وطباعة) |
| توليد Word | كتابة OOXML مباشرة + archive (ZIP) — بمواصفات docx_engine.py |
| الخطوط | IBM Plex Sans Arabic للمتن، Aref Ruqaa للتحية والخاتمة (مفتوحة المصدر، مضمّنة) |
| التاريخ الهجري | hijri (أم القرى) |

## التشغيل والبناء

```bash
flutter pub get
flutter run                # تشغيل على جهاز/محاكي متصل
flutter test               # اختبارات الوحدات
flutter build apk          # APK للتوزيع المباشر
flutter build appbundle    # AAB للنشر في Google Play
```

## ملاحظات النشر في Google Play

- البناء بصيغة AAB (`flutter build appbundle`) بعد إعداد توقيع الإصدار
  (`android/key.properties` + keystore خاص — لا يُرفع للمستودع).
- نموذج «أمان البيانات» في المتجر: كل البيانات محلية، ونص الرسالة فقط
  يُرسل لمزود الذكاء الذي يختاره المستخدم.
- `usesCleartextTraffic` مفعّل للسماح بالاتصال بخوادم محلية (Ollama /
  LM Studio) عبر HTTP داخل الشبكة الخاصة.

## الخصوصية

كل شيء محلي على الجهاز (القاعدة، الترويسات، الملفات المصدَّرة، الإعدادات).
الاستثناء الوحيد: نص الرسالة يُرسل إلى مزود الذكاء الاصطناعي المُعدّ عند
التوليد أو التنقيح.
